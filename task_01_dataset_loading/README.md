# Heart Disease ML

A structured collection of machine learning and data analysis tasks completed as part of the BrainyBeam internship.

The project uses the Cleveland subset of the UCI Heart Disease dataset and focuses on understanding the complete data-processing workflow step by step, including manual dataset loading, statistical analysis, missing-value handling, and later machine-learning tasks.

---

# 📌 Project Overview

This repository contains multiple tasks developed during the internship.

The tasks are intentionally organized separately so that each implementation, report, and result can be reviewed independently.
